# ТЗ: интерактивная карта Нижнего Новгорода · версия 4,8+

## Цель

Мобильная интерактивная карта поездки на 23–26 июля 2026 с четырьмя вкладками
дней, маршрутом на Яндекс Картах и карточками мест.

## Источник данных и правило отбора

- Первичный источник: соседний research-прогон
  `nizhny-novgorod-research-v3-handoff.zip`, файл `entities.csv`.
- Включить все записи, у которых `rating >= 4.8`.
- Исключить записи с рейтингом ниже 4,8, а также без подтверждённого рейтинга.
- Рейтинг и `reviews_count` брать одной парой из 2ГИС.
- Срез данных: 15.07.2026.
- Итоговый состав: 18 мест.

## Состав по дням

1. Чт: Парк «Швейцария», Итальянка, Нижегородский государственный
   художественный музей, Краса.
2. Пт: Темп, Нижегородский кремль, Усадьба Рукавишниковых,
   Верхне-Волжская набережная, Горячо.
3. Сб: Русский музей фотографии, Нижне-Волжская набережная,
   Рождественская улица, Гусь в яблоках, Pinci.
4. Вс: Пакгаузы, Площадь Народного Единства, Самовар да утки, Dodici Grill.

## Функциональность

- Яндекс Maps JavaScript API 3.0; официальный map-widget как запасной режим.
- Переключение четырёх дней без перезагрузки.
- Нумерованные точки и линия маршрута текущего дня.
- Клик по карточке центрирует карту и выделяет точку.
- У каждой карточки: время, рейтинг, количество оценок, категория, описание,
  ссылка на Яндекс Карты и телефон при наличии.
- Погодный блок оформлен как атмосферное небо и содержит сезонную оценку.

## Визуальные требования

- Мобильная версия — один столбец; десктоп — карта и карточки в две колонки.
- У всех 18 карточек должна быть локальная WebP-обложка. Если в research нет
  фотографии, допустима явно обозначенная иллюстративная фотореалистичная обложка.
- Цвет точек: достопримечательности — золотой, еда и бары — розовый.

## Источники истины в проекте

- `build_data.py` — текущий состав и данные карточек.
- `data.json` — результат сборки данных.
- `assemble.py` — шаблон и логика интерфейса.
- `nn-plan-interactive.html` — готовая страница.
- `nizhniy-novgorod-23-26-iyulya-2026.md` — текстовая версия маршрута.

## Проверка перед выпуском

- Ровно 18 уникальных мест.
- У каждого рейтинг не ниже 4,8.
- Нет карточек без рейтинга.
- Все четыре вкладки, точки и ссылки работают.
- В консоли браузера нет ошибок.
- Для публикации использовать разрешённый домен GitHub Pages, не `file://`.
