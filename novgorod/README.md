# Нижний Новгород · 23–26 июля 2026

Готовый файл — `nn-plan-interactive.html`. В нём работают Яндекс Maps JavaScript API 3.0, маршруты, точки и карточки. Текущая версия содержит все 18 мест из research с рейтингом 4,8 и выше; места с меньшим или отсутствующим рейтингом исключены. Если API недоступен, страница автоматически показывает официальный интерактивный виджет с тем же маршрутом. Интернет нужен для карты, фото и внешних ссылок.

Все 18 обложек хранятся локально в `assets/`, поэтому не зависят от временных ссылок Google. Для мест, где research не содержал фотографии, используются иллюстративные фотореалистичные обложки, а не документальные снимки конкретного интерьера.

Из-за ограничения API-ключа страницу нужно открывать через `localhost` или публиковать на разрешённом домене GitHub Pages. При открытии HTML двойным кликом Яндекс Карты не загрузятся.

## Ключ Яндекс Карт

Создайте рядом с `assemble.py` файл `.env.local`:

```dotenv
YANDEX_MAPS_API_KEY=ваш_ключ
```

Файл `.env.local` игнорируется Git. Ключ также можно передать переменной окружения `YANDEX_MAPS_API_KEY`.

## Сборка

```bash
python3 build_data.py
python3 assemble.py
python3 -m http.server 4173
```

После этого откройте `http://localhost:4173/nn-plan-interactive.html`.

Скрипты можно запускать из любой папки: пути вычисляются относительно самих скриптов. Сборка перезапишет `data.json` и `nn-plan-interactive.html`.

## Где менять данные

- `build_data.py` — места, маршруты, сценарии финала и погода.
- `assemble.py` — разметка, стили и логика Яндекс Карт.
- `data.json` — промежуточный машиночитаемый файл; не править вручную, если потом запускается `build_data.py`.

За 3–4 дня до поездки стоит заменить сезонную оценку погоды в `build_data.py` на актуальный прогноз и пересобрать HTML.
