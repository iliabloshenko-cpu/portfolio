1. Omni Support Admin

Проблема
Операторы работали с устаревшим интерфейсом, где данные клиента были разбросаны по разделам без единой логики.
Что сделал
Спроектировал админ-панель для операторов клиентского сервиса: поиск клиентов, управление сложной карточкой с десятками связанных сущностей, механизмы подтверждения изменений (акцепт) и полный аудит-трейл.
3состояния редактированиявместо «непонятно, сохранилось ли»
15+разделов в карточке клиентамасштаб задачи
